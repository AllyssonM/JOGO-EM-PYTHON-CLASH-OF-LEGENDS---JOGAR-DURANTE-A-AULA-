# JOGO-EM-PYTHON-CLASH-OF-LEGENDS---JOGAR-DURANTE-A-AULA-
RPG de luta 2D em Python (pygame-ce) inspirado em animes shonen: 17 heróis originais com uniformes, jutsus finais cinematográficos, substituição e Despertar. Modo História com final decidido pelo seu estilo de luta, Luta vs Máquina, 1v1 local e O Pouso: fazenda e vila do clã para farmar.
